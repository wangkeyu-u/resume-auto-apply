# 简历助手 · 浏览器扩展（零手填桥接）

把招聘网站和本地「简历自动投递助手」连起来，**把你原本要手动做的事全部自动化**：

| 你原来要做 | 现在扩展替你做 |
|---|---|
| 在 BOSS/猎聘 上逐个看职位、手动记录 | 在职位列表页点「① 抓取本页职位」，一键把整页职位抓回本系统并自动匹配、定制 |
| 打开申请页，手动填姓名/邮箱/技能/经历 | 在投递页点「② 填入定制简历」，按表单字段**自动填入为你这个岗位定制好的内容** |
| HR 发来消息，手动想怎么回、手动敲字 | HR 消息自动进系统 → 你点「拟回复」生成话术 → 在聊天页点「③ 采纳回复并填入」自动填进输入框 |
| 最后点发送/提交 | **这最后一下永远是你本人点**（平台强制真人操作，且自动点会触发反爬封号） |

> 红线：扩展**只读取页面、只填空**，从不自动点击「发送 / 提交」。是否发送由你在招聘网站亲自确认。绝不做无人值守冒充聊天。

## 安装

1. 打开 `chrome://extensions`（或 Edge `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`boss-zhipin-extension/`）
4. 固定扩展图标到工具栏

## 使用流程

### ① 抓取真实职位（替代示例数据）
1. 在本系统「个人资料」填好完整履历并保存
2. 打开 BOSS直聘 / 猎聘 等**职位搜索列表页**
3. 点扩展图标 →「① 抓取本页职位」
4. 职位自动回传本系统、自动匹配评分、生成定制简历（仪表盘「职位库 / 待投递」可见）

### ② 自动填申请表（替代复制粘贴）
1. 打开某个职位的**申请 / 投递页**
2. 点扩展图标 →「② 填入定制简历」
3. 扩展先用页面职位名匹配本系统里的职位，再按表单字段（姓名/邮箱/电话/求职意向/自我评价/技能/经历/项目/教育）**自动填入定制内容**
4. 你核对一下，点招聘网站的「提交」

填表**不依赖写死选择器**：扩展按每个输入框的 label / placeholder / name 文本自动匹配字段，
所以对企业官网等任意投递页也能用，无需为每个站点单独配规则。

### ③ 自动聊 HR（替代手敲回复）
1. HR 消息在 BOSS 聊天页出现时，自动进本系统
2. 在仪表盘「沟通」页点「拟回复」生成话术 →「批准」
3. 回到 BOSS 聊天页，点扩展图标 →「③ 采纳回复并填入」
4. 话术自动填进输入框，你检查后点 BOSS 的「发送」

## 配置（默认免改）
扩展默认连接 `http://127.0.0.1:8011`（即本系统）。若你改了本系统端口，在扩展弹出框里改「助手地址」即可。
本地运行默认无需 Token；如需鉴权，在本系统「设置 → 扩展」里生成 Token 并填到弹出框。

## 选择器说明（重要）
招聘站页面结构会变化。职位抓取用了各平台的参考选择器（`content.js` 顶部 `CARD_SELECTORS` / `FIELD_PARSERS`）。
如果某天抓不到，按 F12 查看对应卡片的 class，更新这两个对象即可；填表逻辑走通用 label 匹配，通常不受影响。

## 文件
- `manifest.json` — MV3 扩展声明
- `content.js` — 注入页面：抓职位、按 label 自动填表、填聊天输入框、扫描 HR 消息
- `background.js` — 与本地助手 API 通信、处理弹出框指令
- `popup.html` / `popup.js` — 扩展弹窗 UI

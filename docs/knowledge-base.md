# 岗位知识库

`data/jd_knowledge.json` 为岗位匹配和简历技能提取提供结构化规则，没有训练或微调模型。应用启动时由知识库派生词表。

## 文件与重建

- `data/kb_draft_*.json`：合并脚本使用的原始归纳输入，属于重建依赖。
- `scripts/build_knowledge.py`：合并、去重并刷新知识库元数据。
- `data/jd_knowledge.json`：`_meta` 与 `roles`，包含别名、必需/可选技能、职责和关键词。

从仓库根目录运行：

```bash
python3 scripts/build_knowledge.py
```

该命令会更新知识库文件，运行后应检查差异。

## 历史记录

2026-07-12 的记录报告了 44 个岗位类别、1,131 个去重术语；由知识库派生的提取词表约 1,154 项，早期手写词表约 40 项。一条密集 JD 示例提取了 20 项细分技能，当时全链路自测记录为 58 passed、0 failed。

这些数值来自当时记录，本次目录清理没有重新运行该评估；单条示例不能证明普遍的抽取准确率。历史记录称输入归纳自招聘页和社区，但当前草稿没有逐条 JD 的原始链接、抓取快照和授权记录，因此不能把所有条目称为已核验的真实招聘语料。

覆盖方向包括后端、前端、移动、算法、数据、产品、运营、市场、销售、测试、安全和设计。知识库应作为可审查的匹配规则维护，并补充条目的来源和更新时间。
